# 3 分钟演示脚本（照着念就行）

> 目标：让面试官在 3 分钟内看到「RAG 有指标 → Agent 会调工具 → 写操作有人工闸门 → 工单能沉淀成知识」这条完整链路。
> 全程只用一个浏览器页面，不需要切终端（终端只在第 4 段用一次）。

---

## 0. 开场（20 秒，指着屏幕）

> "这是一个 Docker 场景的 IT 服务台 Agent。员工用中文提问，它检索英文官方文档和历史工单，
> 给出带出处的处置建议；需要建单、结单时调工具，但**写操作前一定停下来等人确认**；
> 全程有 Trace，可以回放、可以评测。"

**先别急着提问**，先点一下右上角「轨迹」再关掉——让面试官知道侧栏是存在的。

---

## 1. RAG：带出处回答（60 秒）

**输入**：

```
Docker 容器端口被占用怎么排查
```

**边等边说**：

> "注意两个细节：
> ① 回答是**逐字流式**出来的；
> ② 每条结论后面都有**出处路径**——这是检索到的真实文档段落，不是模型编的。"

**指着出处说**：

> "知识库是 Docker 官方文档仓库的 932 篇 markdown，切成 8,794 个 chunk。
> 评测集 65 条中文提问、人工标了 gold 文档，最终配置 hit@5 = 0.767。"

如果面试官问"为什么不直接问 GPT"：

> "因为服务台场景要**可追责**。给工程师的回答必须能点回原文，
> 而且我们内部工单里的处置经验，通用模型根本没有。"

---

## 2. 工具编排 + 写操作闸门（60 秒，最重要）

**输入**：

```
帮我建个 P2 工单，标题「Docker Desktop 启动卡住」，客户 cust-003
```

**预期**：弹出确认框，显示 `create_ticket` 的完整参数。

**先点「拒绝」**：

> "注意——它没有建单。这不是前端拦的，是**后端的 interrupt**：
> 图执行到写操作就暂停，参数落进 checkpoint。就算你绕过界面直接调 API，一样会被拦住。"

**再问一次，这次点「允许」**：

> "这时候才真的落库。而且我会习惯性去数据库验一遍，不信任'已创建'这三个字。"

（如果面试官想看，切终端跑：）

```bash
.venv\Scripts\python.exe -c "import sqlite3;c=sqlite3.connect('data/helpdesk.db');print(c.execute(\"select id,title,state from tickets order by created_at desc limit 3\").fetchall())"
```

---

## 3. 记忆（30 秒）

**输入**：

```
我是 premium 客户，我们用的是 Docker 4.34
```

然后点「记忆」抽屉 → 看到 `tier: premium`、`version: 4.34`。

**接着说**：

> "这是**跨会话**的长期记忆，存在 Redis 里，按 user_id 隔离。
> 分三层：checkpoint 管对话能不能接着聊，Redis 管记不记得你，runs/steps 管为什么这么答。"

---

## 4. 闭环：工单变成知识（40 秒，差异化亮点）

**先问一个知识库答不全的问题**：

```
Docker Desktop 卡在 Starting，完整排障步骤有哪些？
```

**指着 Trace 说**：

> "看第 3 步——它自己判断知识库不够，**降级去做了网页搜索**，
> 第 4 步用网络结果重写了答案。这是两级降级里的第二级。"

**然后演示结单沉淀**：

```
工单 synthetic#0002 已经解决了，根因是 BIOS 没开虚拟化；解法是开启 VT-x 并 wsl --update。帮我结单并沉淀到知识库。
```

**指着观察结果**：

> "它把工单写成了 `cases/synthetic#0002` 这篇文档，切了 3 个 chunk，进了同一个索引。
> 也就是说——**下次有人问同类问题，答案直接来自我们自己的处置经验**，而不是官方文档。"

**验证**：

```
BIOS 没开虚拟化导致 WSL2 起不来怎么解决
```

> "出处变成了 `cases/synthetic#0002`。这就是我理解的'闭环'。"

---

## 5. 收尾（20 秒）

> "整个过程有几个我特意做的地方：
> ① **每个结论有出处**；
> ② **写操作有闸门**，拒绝就真的不执行；
> ③ **工具重复调用会被中间件拦**（同一参数第二次直接短路）；
> ④ 所有决策都有数字支撑——比如我实测跨语言重排会让 hit@5 掉 5 个点，所以最终配置**不用重排**。"

---

## 备用问答（面试官可能问）

| 问题 | 一句话回答 |
|---|---|
| 为什么不用 Dify/RAGFlow？ | 平台能跑起来，但我讲不清每个默认参数为什么是那个值；自己写才能把取舍说清楚 |
| 数据是真的吗？ | 文档和 Issues 是真实开源数据（锁 commit 可复现），只有客户/SLA 是合成的，标了 `is_synthetic` |
| 指标怎么算的？ | 65 条中文问题，人工标 gold 文档路径，用路径前缀匹配 —— 所以切 chunk 大小不影响评测 |
| 最大的坑？ | Chroma 在第 3,441 行静默丢写，根因是系统 TEMP 对 Python 不可达；这件事教会我"永远验证副作用，别信返回值" |
| 如果上线还差什么？ | 并发（现在一把全局锁）、鉴权、评测集扩到 300+、案例自动去重 |
